# Docklane v0.1.0-alpha.2

Docklane's second public alpha removes the local controller-image build from
the normal installation path. Download the release binary, review the plan,
and install: Docklane now selects its matching published runtime image.

## What changed

- Publish the controller and restricted probe image to Docker Hub for Linux
  `amd64` and `arm64`.
- Make release binaries select
  `lcaohoanq/docklane:v0.1.0-alpha.2` automatically.
- Keep development binaries on the explicit `docklane:local` image.
- Build the container image from the exact binaries whose checksums are
  published in the GitHub Release.
- Publish an immutable version tag together with the moving `alpha` channel.
- Attach build provenance and an SBOM to the multi-platform image.

## Install

Follow the
[first-alpha installation guide](https://github.com/lcaohoanq/docklane/blob/v0.1.0-alpha.2/docs/first-alpha.md).
Download the archive for your architecture together with `checksums.txt`, and
verify the checksum before installing it.

The managed installer pulls the matching Docker Hub image automatically. A
local Docker build is no longer required for the normal installation path.

## Supported hosts

- Debian 12 or Arch Linux with systemd
- Docker Engine at `/var/run/docker.sock`
- `dnsmasq` plus `systemd-resolved`
- Linux `amd64` and `arm64`

Docker socket access is equivalent to root-level control of the machine.
Install this alpha only on a development machine or VM whose local DNS, trust
store, Docker networks, and ports 80/443 Docklane may manage.

## Alpha limitations

- Local development domains only; purchased and public DNS are out of scope.
- Rootless and remote Docker engines are not supported.
- The controller UI/API binds only to `127.0.0.1:4646`.
- `docklane upgrade` migrates installation-manifest schemas; it is not yet a
  general binary or container-image updater.
- Automated certificate rotation and signed release provenance are post-alpha
  work.

Please report problems at
[GitHub Issues](https://github.com/lcaohoanq/docklane/issues).
