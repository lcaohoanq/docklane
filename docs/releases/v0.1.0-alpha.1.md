# Docklane v0.1.0-alpha.1

Docklane's first public alpha turns Docker containers into stable, trusted
local HTTPS applications without publishing a different host port for every
container.

## What works

- Install a global Traefik gateway on ports 80 and 443.
- Resolve `*.docker.home.arpa` locally with `dnsmasq` and
  `systemd-resolved`.
- Create and trust a machine-local CA covering the base domain and wildcard.
- Discover Docker and Compose workloads.
- Create a route with `docklane app enable`, then wait until it is actually
  reachable before presenting the link.
- Diagnose control-plane, Docker, network, Traefik, upstream, DNS, redirect,
  TLS, and HTTPS health with `docklane doctor`.
- Review machine changes before token-gated install and uninstall.
- Roll back interrupted or failed installation operations.

## Supported hosts

- Debian 12 or Arch Linux with systemd
- Docker Engine at `/var/run/docker.sock`
- `dnsmasq` plus `systemd-resolved`
- Linux `amd64` and `arm64`

Docker socket access is equivalent to root-level control of the machine.
Install this alpha only on a development machine or VM whose local DNS, trust
store, Docker networks, and ports 80/443 Docklane may manage.

## Install

Follow the
[first-alpha installation guide](https://github.com/lcaohoanq/docklane/blob/v0.1.0-alpha.1/docs/first-alpha.md).
Download the archive for your architecture together with `checksums.txt`, and
verify the checksum before installing it.

The complete release path was rehearsed from the `docklane-clean` snapshot on
a Debian 12 VM using only the release archive. The test covered fresh install,
an nginx HTTPS route with no published host port, diagnostics, private-key
permissions, reviewed uninstall, and exact-state rollback.

## Alpha limitations

- Local development domains only; purchased and public DNS are out of scope.
- Rootless and remote Docker engines are not supported.
- The controller UI/API binds only to `127.0.0.1:4646`.
- `docklane upgrade` migrates installation-manifest schemas; it is not yet a
  general binary or container-image updater.
- Automated certificate rotation and signed release provenance are post-alpha
  work.

Please report problems at
[GitHub Issues](https://github.com/lcaohoanq/docklane/issues).
