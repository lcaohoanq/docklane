The Docklane website does not require an account and does not send data to the
Docklane application or controller.

## Local preferences

The site stores theme preference and, when analytics is configured, analytics
consent in your browser's local storage.

## Google Analytics

The production build supports Google Analytics, but tracking is disabled when
no measurement ID is configured. When enabled, the Google Analytics script is
not loaded and no analytics request is sent until you select **Accept**.

Selecting **Decline** is remembered locally. You can clear the choice in browser
site data. No advertising or cross-site personalization is configured by
Docklane.

For project questions, use the public
[GitHub repository](https://github.com/lcaohoanq/docklane).
