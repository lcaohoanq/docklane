# Docklane v0.1.0-alpha.1

The first public alpha packages the Docklane controller, CLI, embedded Svelte
UI, local Traefik gateway, DNS, and TLS installation workflow.

## Included

- Discover Docker and Compose workloads.
- Create durable routes with stable `*.docker.home.arpa` names.
- Reconcile routes across container recreation.
- Generate and validate a complete Traefik HTTP-provider document.
- Plan, install, diagnose, and uninstall managed host resources.
- Persist an ownership-aware installation manifest.
- Provide release archives for Linux `amd64` and `arm64`.

## Safety

This release is intended for a development machine or VM. Docker socket access
is root-equivalent, and the installer manages local DNS, certificate trust,
Docker networks, and ports 80/443.

## Known limitations

- The initial release installation path builds its controller image locally.
- Rootless and remote Docker engines are unsupported.
- The controller UI/API is local-only at `127.0.0.1:4646`.
- Public ingress, ACME, and automated certificate rotation are out of scope.

Use [v0.1.0-alpha.3](./v0.1.0-alpha.3/) for the current alpha release.
