<div class="landing-eyebrow">Local container gateway</div>

Docklane discovers Docker workloads, assigns stable local domains, and gives
Traefik one complete routing configuration to serve them over HTTPS.

<div class="domain-demo"><span></span>excalidraw.docker.home.arpa</div>

<section class="landing-section">
  <header>
    <div class="landing-eyebrow">Why Docklane</div>
    <h2>One gateway for every local container.</h2>
    <p>
      Stop publishing and remembering a different host port for every
      application. Keep traffic inside Docker until it reaches the shared
      gateway.
    </p>
  </header>
  <div class="feature-grid">
    <article class="feature-card">
      <strong>Stable names</strong>
      <p>Routes identify Compose workloads, so they survive container recreation.</p>
    </article>
    <article class="feature-card">
      <strong>HTTPS by default</strong>
      <p>Local DNS and a machine-local CA provide trusted names under <code>docker.home.arpa</code>.</p>
    </article>
    <article class="feature-card">
      <strong>Inspectable changes</strong>
      <p>Plan, apply, diagnose, upgrade, and uninstall through one reversible control plane.</p>
    </article>
  </div>
</section>

<section class="landing-section">
  <header>
    <div class="landing-eyebrow">How it works</div>
    <h2>From Docker service to local HTTPS in three steps.</h2>
  </header>
  <div class="steps-grid">
    <article class="step-card">
      <span class="step-number">1</span>
      <strong>Discover</strong>
      <p>Docklane reads running Docker and Compose workloads without changing their Compose files.</p>
    </article>
    <article class="step-card">
      <span class="step-number">2</span>
      <strong>Route</strong>
      <p>Choose an internal port and assign a predictable local hostname.</p>
    </article>
    <article class="step-card">
      <span class="step-number">3</span>
      <strong>Verify</strong>
      <p>Docklane checks DNS, TLS, Traefik, networking, and the upstream as separate layers.</p>
    </article>
  </div>
</section>

<section class="landing-section">
  <header>
    <div class="landing-eyebrow">Request path</div>

      Application traffic stays on Docker networks. Docklane manages the
