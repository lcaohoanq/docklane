# Docklane brand

Docklane is a local container gateway. Its visual language combines routing
lanes, a gateway, and the letter D.

## Logo

- `logo-mark.svg` is the primary symbol for square placements.
- `logo-horizontal.svg` is the primary lockup on light surfaces.
- `logo-horizontal-dark.svg` is the lockup for dark surfaces.
- Keep clear space around the logo equal to the width of one lane in the mark.
- Do not rotate, stretch, outline, or recolor individual parts of the mark.

## Color

| Token | Value | Use |
| --- | --- | --- |
| Lane | `#45D483` | Primary actions, healthy routes, links |
| Lane bright | `#72E3A6` | Dark-surface emphasis |
| Asphalt | `#0A100D` | Primary dark background |
| Concrete | `#F4F7F5` | Primary light background |
| Amber | `#E6AD52` | Pending and warning states |
| Coral | `#F27676` | Errors and destructive actions |

Both applications consume `tokens.css`. New colors should be introduced there
instead of being added as one-off values.

## Typography

- Space Grotesk: product name and display headings.
- Inter: interface and documentation text.
- A system monospace stack: commands, domains, ports, and machine output.

## Voice

Be direct, calm, and operational. Explain what Docklane will change before
asking the user to apply it. Avoid claims that cannot be verified and always
identify alpha limitations.
